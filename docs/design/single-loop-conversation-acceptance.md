## 实现和删除范围

- 同会话单一执行循环，补充输入持久排队，在完整响应或工具结果边界消费；不同会话可并行。
- 插话唤醒等待工具，返回任务 ID；取消使用独立信号，可中止静默模型读取与当前直接执行。
- 原卡取消绑定原 sid/run_id，覆盖旧卡、长 ID、跨聊天和权限校验。压缩取消也用完整身份定位。
- 主历史先持久写再更新 SDK；压缩冻结前缀，保留尾部、原始转录、媒体与揭示工具。
- 新 run 开始修复缺失工具结果；取消、预算耗尽和 provider 失败均保持调用配对，不重放副作用。
- 后台结果投递去重，失败不确认送达；父回答取消后保留结果到下一轮。内部任务不因恢复队列自动重跑。
- 停机先停止调度器领取新任务，排空已领取任务并记录结果，随后关闭入场、收尾对话。
